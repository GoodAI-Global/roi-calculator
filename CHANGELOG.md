## [0.1.0] - 2026-01-06

### Added
- Manufacturing ROI calculator with OEE and downtime metrics
- Insurance ROI calculator with claims processing and fraud detection
- Enterprise financial metrics: NPV, IRR, TCO, Profitability Index
- Sensitivity analysis with conservative/expected/optimistic scenarios
- PDF export with company branding
- Scenario comparison (save and compare multiple scenarios)
- Benchmark citations with sources (McKinsey, Deloitte, Gartner)
- Calculation audit trail showing step-by-step methodology
- ErrorBoundary for graceful error handling
- Comprehensive test suite (88 tests)
- CI/CD pipeline with GitHub Actions

### Security
- Input validation on all calculator inputs
- Text sanitization in PDF export
- No external API calls or data storage

### Documentation
- README with What it is / What it isn't sections
- CONTRIBUTING guidelines
- SECURITY policy
